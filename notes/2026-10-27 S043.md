**Editor/UX work (browser-tested via Playwright):**
- **Images same-origin**: v2 serves `/raw/<CAM>/<day>/<file>` itself
  (traversal-safe, content-types, cache headers, **HEAD** support); the viewer's
  href is relative   " no v1 dependency, no mixed content.
- **Nav speed**: the assessed view cost ~1.1 s per scan  -- 3 scans/page     4 s
  pages. **Materialised `assessed_pairs`** (rebuild after pour + per-image refresh
  from ingest/assess/workflow-transition/editor-save), `idx_ap_order (day DESC,
  camera, filename)` (page 0.0004 s), and **categories cached per universe in
  scan_state** (`editor.categories.<uni>`, was a 0.48 s detections-scan per page;
  invalidated on publish / assessment-new-label). Image page 2.9 s   ' 0.53 s;
  queue page 2.2 s   ' 0.05 s.
- **Deterministic ordering**: every queue always sorts (default `day DESC, camera,
  filename`); nav rank = window function over the WHOLE source in a subquery, then
  filter to the row (a WHERE-filtered window computes "1 of 1"   " likewise
  COUNT(*) OVER ()).
- **Reject/claim/release walk the originating queue** (S038 doctrine restored):
  action forms carry q+sort; `_action` computes the NEXT image in that queue
  BEFORE the transition and redirects there; tail   ' prev; prev/next re-derive live
  (so reverse-after-reject shows previous-but-one naturally).
- **Claim/lock semantics**: edit layer only when claimed AND by-you;
  **poured orphans** (claimed, claimant NULL) are adoptable   " first save/claim
  adopts (claimed_by stamped). Sticky edit mode: `?edit=1` rides every action/back
  URL; absent = keep; `edit=0` = off.
- **claimed  'rejected edge added** (schema 13  '14 edges + editor role grant; live DB
  patched): from a claim in edit mode you can reject directly; the human xml dies
  with it (xml_doc_id NULL'd + dets + file   " was an FK failure before).
- **    reclaim** (POST /editor/reclaim + editor.reclaim_boxes): discard the human
  xml in flight, re-seed from the assessment (same seed rule as first-claim:
  assessment's top finds    0.25, top 10, **deduped by (label, box)** keeping best
  score   " the pour has multiple producers with identical top rows). Data repair
  walked the Pi's human docs deleting duplicate det rows.
- **The interaction model**: background drag = PAN (draw-on-drag retired); menus:
  box (    edit /     focus /     un-focus /   --' delete   " only the   --' badge stays on the
  box) + background (    new box = 10%-box seeded at the click /     un-focus);
  right-clicking an unselected box selects it + bg menu; double-click a selected
  box =     focus. **Capture-phase swallowing** of contextmenu + button-2 pointerdown
  over the image surface so the host (VS Code) menu never appears.
- **Focus geometry**: box spans     **3/4 of either dimension** (min(zX,zY), floor
  1.25, cap 8), centered via wrap-local translate (`PX = cw/(2Z)   ' boxCentreLocal`   "
  the old double-scaled formula + old clamps blocked centring); pan clamp = the
  true coverage range `[cw/Z   ' cw, 0]`; handlers also on the clip's whole surface
  (the "dead strips" around a zoomed image now pan + menu). Out-of-bounds pan
  impossible (huge drags verified clamped both directions).
