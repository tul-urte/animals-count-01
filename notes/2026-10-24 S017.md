**We picked up the plan at Phase D (not A)**   " the overnight re-assessment was already done (S014/S015). The user drove the design; I built it. The core idea (user's): the "product" is the output of more than one model, so work in **layers**, and a **human pseudo-model file is created explicitly per user**   " never by silently copying a non-human file.

**The Layer model (supersedes the original Phase D bullets in the plan):**
- **Layer 0 (immutable)** `/yermo/animals-count/cameras/CAM-XX(-CLASSIFIED)/...`   " the bank; triage never writes here.
- **Layer 1 (mutable, per-user)** `/yermo/animals-count/edit/<camera>/<day>/<user>/<base>.xml`   " a human's edited pseudo-model. Created **empty** on claim; boxes seeded from any graph / the current model; label/box/score/attributes all editable.
- **Layer 2 (product)** `/yermo/animals-count/export/<camera>/<day>/<base>.xml`   " confirmed edits only.

**Locking & outcomes (per *image*, keyed `camera|day|filename`):**
- `active_edits` table = the lock. **Claim** = lock + create empty Layer 1 XML. **Release** = unlock + delete that user's Layer 1 file. While locked, other users see "Locked by <user>" and cannot claim.
- `image_status` table = the outcome: `confirmed`   ' exported; `rejected`   ' not; *released* = no outcome (implicit).

**Editor** (`/editor/<cam>/<day>/<file>?user=`): lock banner + outcome pill; **seed buttons** (one per available old-era graph + a `(current model)` source) that append that source's boxes into the working set (server-side GET); editable box table (label/xmin/ymin/xmax/ymax/score + add/del) and attribute table; **Save / Save+Confirm / Save+Reject / Release**. Day-detail tiles now link straight into the editor (defaults `user=alaric`).

**Export engine** (`/editor/export`): scans all Layer 1 files; if a single source image was edited by **more than one user it HARD-FAILS** (recorded in `export_conflicts`, nothing copied)   " otherwise copies each confirmed image's single Layer 1 XML to Layer 2. This enforces "explicit selection" (a file in Layer 1 = a human actively worked it) and refuses to guess between humans.
