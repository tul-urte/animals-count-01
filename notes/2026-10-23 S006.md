## S006    2026-10-23 18:15    IMX500 Conversion Research
The modern toolchain is fully **pip-installable, no Sony portal/account needed**:
- **Edge-MDT** (`pip install edge-mdt[pt]`): bundles Sony MCT (quantization), IMX500 Converter (`imxconv-pt`), target-platform configs. Latest 1.3.0 (2026-04); `imx500-converter` 3.19.x. Ubuntu 22.04 / Python 3.11 / OpenJDK 17 recommended; torch 2.3  "2.6, opset 15  "20.
- **Flow**: PyTorch module   ' MCT INT8 PTQ (representative images, ~100  "200, preprocessed exactly as training)   ' `mct.exporter.pytorch_export_model`   ' `imxconv-pt`   ' `packerOut.zip`   ' **on a Raspberry Pi**: `imx500-package`   ' `network.rpk`   ' Picamera2.
- **Our plain `torch.onnx.export` ONNX is NOT the converter input**   " the converter requires MCT-quantizer metadata; quantization must run from the PyTorch module. Our existing ONNX is still useful as a portability/validation artifact.
- **Native Windows ARM64 blocked**: `edge-mdt-cl[torch]` pins torch 2.6/onnxruntime 1.21 (no win_arm64 wheels). **WSL2 Ubuntu 22.04 (ARM64) is the reliable path** (matches Sony's tested env; no emulation). The Java converter backend itself is cross-platform (needs OpenJDK 17).
- **Model fit**: our anchor-free 20 --20 grid head uses only supported ops; decode+NMS can run **host-side on the Pi** (Picamera2 ships an anchor-free NanoDet-style decoder+NMS to copy: `postprocess_nanodet.py`), or later on-sensor via `edge-mdt-cl` custom NMS layers (Ultralytics `_pp` pattern). Start host-side (simpler, guaranteed).
- **Important preprocessing note**: IMX500's on-sensor ISP supports only integer affine normalization; our ImageNet mean/std must be folded into the model graph (Sub/Div ops are supported), with the representative dataset generated identically.
- **Packaging runs on the Pi itself** (`imx500-package`, from `imx500-tools`/`imx500-all` apt packages). Documented minimum: Pi Zero 2 W (original armv6 Zero unverified/not listed).
- Ultralytics' `export format="imx"` (ultralytics/utils/export/imx.py) is the best public reference implementation of this pipeline for PyTorch models.
