## S025    2026-10-25 (early afternoon)    Phase E  -1: box tidy   " same-label containment dedup at the parse gate

**The first roadmap item shipped: "picods should remove duplicate boxes, e.g. a smaller box of the same category inside a larger one of the same category."** The COCO-experiment scene (mug + two bottles on a windowsill) produced exactly that: a small `cup` box inside a big `cup` box, a small `bottle` inside a big `bottle`, frame after frame   " the firmware NMS suppresses *overlapping* candidates but not *nested* ones, so the pair survives as two detections.

**Design (the parse-gate doctrine again   " what you see is what ships):**
- **Geometry in `lib/boxes.py`**: `box_contains(box1, box2)` (strict corners containment, shared edges count, degenerate boxes contain nothing) + `drop_contained_same_label(detections)`   " drop every same-label detection fully inside another same-label box; **the outer box survives**; mutual containment (only possible for identical boxes) keeps the earlier-in-list so a pair can't eliminate each other.
- **Gate in `parse_detections`** (demo): after the threshold/validity gates, *before* the contender filter, gated by hot key **`DETECTION_DROP_CONTAINED`** (default **True**)   " one switch governs live overlay, `latest.xml`, storage images and the XML sidecars alike. Placed before top-K so dropping a nested duplicate frees a top-K slot for a *distinct* same-label object (with `DETECTION_MAX_PER_LABEL=2` the same frame that used to spend both cup slots on big-cup+small-cup now keeps big-cup and can show a second distinct object).
- **Config plumbing**: `cam_config.py` default, documented key in `cam.properties`, and a `bool` row on the `/config` page (`HOT_KEYS`)   " flippable live, applied within ~1.5 s.
- **Offline diagnostic** `diagnostics/check_box_tidy.py` (fixture-first, no camera/NPU): 9 `box_contains` cases + 7 gate cases (inner same-label dropped / chain keeps only outer / identical first-wins / partial overlap both stay / cross-label stays / empty / large coords). **Fixture-first paid off again**: the identical-boxes case caught mutual containment eliminating both   " fixed before ever touching the node. `diagnostics/sweep_containment.py`   " reads `latest.xml` on the node and tallies same-label containment per frame (the measurement instrument for before/after).

**Deploy to picods101** (atomic temp+`mv`, `dos2unix`, backups taken then removed): pre-deploy diff proved the node's `boxes.py`/demo/`cam_config.py` matched git HEAD byte-for-byte, so the live delta was exactly this change. Node's `cam.properties` is root-owned and carries live experiment values (`DETECTION_FRAME=( 298, 461, 1487, 1004 )`, `DETECTION_MAX_PER_LABEL=2`)   " key **appended** via `sudo tee -a`, not overwritten; the repo copy documents it instead.
