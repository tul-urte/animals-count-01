**Learnings (hard-won):**
- Never scp-over-write a running bash script: deploy via temp + `mv` (atomic inode swap). Running bash re-reads by byte offset.
- The NPU is exclusive: diagnostics that load firmware must stop the detector first (cron auto-restarts within 60 s).
- `.gitattributes` pins LF but **fresh working-tree files still carry CRLF** (autocrlf=true); normalize before scp or bash chokes on `set -e\r`. All kit files normalized; rotation test caught it twice.
- scp -r into an existing dir nests; delete-then-copy for clean deploys.
- rotate placement matters: after can_start = once per committed start (~1  "2 archives/day); at supervisor entry = one per night no-go (~dozens/day).
